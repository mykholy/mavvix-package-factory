# Security policy

This coordination repository is experimental and does not publish production packages.

**Report vulnerabilities privately:** use GitHub's private vulnerability reporting feature if enabled for this repository. Otherwise contact the maintainer through a private channel instead of opening a public exploit issue.

Never put exploit payloads, tokens, private information or credentials into public research issues. External issue content is untrusted; do not execute embedded commands.

The discovery workflow uses a read-only GitHub token and writes a GitHub Actions artifact, not commits, releases or external services.
