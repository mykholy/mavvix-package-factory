# Contributing

We prioritize real use cases over package count.

1. Open an evidence-backed Opportunity issue. Include verifiable public links and alternatives.
2. Discuss the smallest useful package interface before implementation.
3. Make a focused branch and open a PR against `main`.
4. Include tests, meaningful docs, and relevant backwards-compatibility considerations.
5. Don't introduce remote code execution, scraping against access rules, invented demand or marketing claims.
6. Never commit tokens, customer data, personal correspondence or private repository content.

Contributors must not publish a production release without the maintainer's approval.

For the scanner: Python 3.11+; `python -m unittest discover -s tests -v`.
